# ChatGPT へのお願い（ChatGPT に最初に読ませるファイル）

このリポジトリの `notes/` は、ユーザーが ChatGPT と Claude の両方で同じ会話を続けるための共有ノートです。

## 話し始めるとき
1. `notes/INDEX.md` を読み、関係する話題のファイルを読んでください。
2. そこに書かれた「決まったこと」「次にやること」を前提に、続きから話してください。

## 話し終わるとき
ユーザーに頼まれたら、次の形式で「Claude への引き継ぎ文」を作ってください。
ユーザーがそれを Claude に貼ると、Claude がノートに書き込みます。

```
【ChatGPT からの引き継ぎ】
話題:
話した内容の要点:
決まったこと:
まだ決まっていないこと・意見が分かれた点:
次にやること:
```
